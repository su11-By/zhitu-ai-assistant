# 智途 AI 助手 — 基于任务意图的 AI 学习助手工作台

面向课程学习和答辩准备场景的 AI 辅助系统，集成了知识库管理、智能问答、深度研究、任务管理和工作台组织等功能。

## 环境要求

- **Node.js** >= 18
- **LM Studio** — 本地 AI 模型运行环境（[下载地址](https://lmstudio.ai/)）
- **AI 模型**（在 LM Studio 中加载）：
  - 对话模型：推荐 Qwen2.5-3B-Instruct 或更高版本
  - 嵌入模型：推荐 nomic-embed-text-v1.5（用于 RAG 向量检索）

## 快速开始

```bash
# 1. 克隆项目
git clone <仓库地址>
cd 期末项目1

# 2. 安装前端依赖
npm install

# 3. 安装后端依赖
cd server
npm install
cd ..

# 4. 启动 LM Studio
#    - 加载对话模型（如 Qwen2.5-3B-Instruct）
#    - 加载嵌入模型（如 nomic-embed-text-v1.5）
#    - 确认本地 API 服务运行在 http://127.0.0.1:1234

# 5. 启动后端搜索代理服务（端口 3001）
npm run server

# 6. 另开一个终端，启动前端开发服务（端口 5173）
npm run dev
```

启动后访问 **http://localhost:5173**。

也可以一条命令同时启动前后端：

```bash
npm run dev:all
```

## 功能模块

| 模块 | 说明 |
|------|------|
| 项目总览 | 展示知识条目、任务数量、工作台卡片和问答记录 |
| 工作台 | 卡片式信息组织，支持文本/代码/图表/脑图/表格/文档 |
| 知识库 | 个人库/团队库、多格式导入、自动分类标签、检索溯源 |
| 智能问答 | 双源问答（知识库+全网）、深度研究、多模态理解 |
| 任务管理 | 增删改查、优先级、截止日期、状态统计 |
| 设置 | 主题切换、数据导出、演示数据恢复 |

## 技术栈

- **前端**: Vue 3 + Vite 5 + Pinia + Vue Router
- **后端**: Express（搜索代理、网页抓取）
- **AI**: LM Studio + Qwen 模型（OpenAI 兼容 API）
- **向量存储**: IndexedDB（浏览器端）
- **数据持久化**: localStorage

## 当前实现亮点

- 完整 RAG 链路：文档解析 → 分块 → 嵌入 → 向量存储 → 语义检索 → 增强回答
- IndexedDB 向量存储，支持多知识库隔离、文档增删、相似度检索
- 11 种 AI 技能系统，覆盖设计/规划/创作等领域
- 双源问答：知识库资料 + 联网搜索联合回答，标注来源
- 流式对话输出 + Token 级上下文窗口管理
- 用户认证系统 + 多用户数据隔离
- CSS 变量主题系统，浅色/深色一键切换
- LM Studio 不可用时自动回退到本地模拟响应

## 当前局限

本项目为前端原型系统，以下能力为演示版实现：

- 暂未接入真实文件解析服务
- 暂未接入云端大模型 API
- 暂未实现多人协作与实时同步

## 项目总结

本项目完成了一个具备清晰定位、完整界面结构和核心交互逻辑的 AI 学习助手原型。它不仅能展示前端工程实现能力，也能体现知识管理、智能问答和产品交互设计思路，适合作为课程期末项目进行答辩展示。
