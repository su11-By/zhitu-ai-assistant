01

项目背景与问题

在学习和答辩准备过程中，资料来源分散，任务、讲稿、设计说明和参考资料分布在不同平台中，难以统一整理和快速调用。

  • 📂 资料散落在微信、网盘、本地文件夹
  • 🔍 查找特定内容需要反复翻阅
  • 📋 任务安排与知识管理割裂
  • 💬 通用 AI 缺乏课程知识上下文
02

解决方案：AI 学习助手工作台

把知识整理、智能问答、任务管理和工作台组织整合在一个系统中，面向课程学习和答辩准备场景。

📊 项目总览 统计数据与系统全貌
🗂️ 工作台 卡片式信息组织
📚 知识库 导入·分类·检索·溯源
💬 智能问答 双源问答 + 深度研究
✅ 任务管理 优先级·截止日期·统计
⚙️ 设置 主题切换·数据导出
03

核心模块：知识库管理

实现从建库、导入、整理到检索溯源的完整链路。

📄 文档导入 → 🔤 文本分块 → 📐 向量嵌入 → 💾 向量存储
🔎 语义检索 → 📎 上下文增强 → 🤖 AI 生成回答
  • 个人库 + 团队库双层结构
  • 支持 PDF / Word / PPT / TXT 多格式导入
  • 自动分类标签与来源记录
  • 关键词搜索与语义检索
  • 来源溯源卡片展示
04

核心模块：智能问答与深度研究

💬 双源问答

知识库资料 + 全网摘要联合回答，附带来源溯源卡片

🔬 深度研究

生成报告提纲、思维导图结构和研究产物

🖼️ 多模态理解

图片、表格、代码、音频的统一分析入口

AI 技术方案
主模型 DeepSeek V4 Flash · OpenAI 兼容格式 · 流式输出 · Token 级上下文管理
05

工作台与任务管理

🗂️ 工作台

  • 卡片式信息组织
  • 支持文本 / 代码 / 图表 / 脑图 / 表格 / 文档
  • 拖拽排序与详情查看
  • 答辩材料统一收纳空间

✅ 任务管理

  • 新增 / 编辑 / 删除任务
  • 优先级设置（高 / 中 / 低）
  • 截止日期与完成状态
  • 任务统计面板
